# Nexus 语言规范（1.1.0）

> 本规范对应 **Nexus 1.1.0 的 C 引擎**（`解释器源代码/nexus.c`）。
> 中文语法详解见 `语法手册.md`，全部别名见 `别名总表.md`。

---

## 1. 范围与术语

Nexus 是一门前缀节点语言。本规范定义：

- 词法与语法；
- 值的表示、真值、相等与数字边界；
- 求值规则、特殊形式、闭包与信号；
- 程序结果与错误；
- 运行时接口；
- 引擎限制与一致性要求。

**“无宿主”**：解释器不依赖 Python、JavaScript、虚拟机或任何外部宿主进程。
词法、语法、求值、值模型、JSON、存储、时钟、程序加载均由 C 实现。
I/O 通过 C 标准库与操作系统完成（stdout、文件、时间），这是运行时的一部分，不是外部宿主。

## 2. 词法

```ebnf
program    := expr* EOF
expr       := node | seq | atom

node       := '(' word expr* ')'
            | '⟨' word expr* '⟩'
            | '(' ')'
seq        := '[' expr* ']'
atom       := number | string | bool | nil | word

word       := 除空白、分隔符外的连续 UTF-8 字符
number     := '-'? ( digits ('.' digits*)? | '.' digits ) ( [eE] [+-]? digits )?
string     := '"' chars '"' | "'" chars "'"
bool       := '#t' | '#f' | '⊤' | '⊥' | '◉' | '◯'
nil        := '◌' | '○' | '⌀'
```

### 2.1 空白与分隔符

- 空白：空格、`\t`、`\r`、`\f`、`\v`、换行；
- 分隔符：`(` `)` `[` `]` `,` `;` `"` `'` `⸢` `⸣`；
- `⟨` `⟩` 与 `(` `)` 完全等价；
- 逗号 `,` 为可选分隔符，忽略。

### 2.2 注释

- `;` 到行尾；
- `⸢ … ⸣` 块注释，可跨行；
- 无 `//`、`/* */` 注释。

### 2.3 字符串

单双引号等价；转义：`\n \t \r \b \f \\ \" \'`。
其他 `\x` 保留 `x` 本身（不解析 `\uXXXX`）；字符串不可跨行，不可含未转义引号。

### 2.4 数字

- 无小数点/指数：整数；超过 ±2^53 转浮点；
- 有小数点/指数：双精度浮点；
- `-` 仅在后面是数字/`.` 时开始数字，否则是词的一部分。

### 2.5 标识符

除空白、分隔符、引号、注释符号外的连续字符。允许 `+`、`->`、`store.list`、中文等。

## 3. 值

| 类型 | 表示 |
|---|---|
| void | `◌` |
| bool | `#t` / `#f` |
| int | 64 位有符号，安全范围 ±2^53 |
| float | IEEE 754 双精度 |
| string | UTF-8；长度/索引/切片按 Unicode 码点 |
| list | 有序序列 |
| record | 保序键值对；键为非纯数字字符串 |
| function | 闭包或内置函数 |

### 3.1 真值

仅 `#f` 与 `◌` 为假；其余（含 `0`、`""`、`[]`、空记录）为真。

### 3.2 相等

- 数字按数值（`1 == 1.0`）；
- 字符串按内容；
- 列表逐元素、记录按键值深度相等；
- bool/void/function 按类型与标识。

### 3.3 数字归一化

- 整数值的 float 在 `norm` 与算术结果中转为 int（若在安全范围）；
- 超出 ±2^53 的整数运算结果用 float 表示；
- `/` 能整除得 int，否则 float；除零为 `runtime divide-by-zero`；
- `%` 向零截断（`(% -7 3) = -1`）；
- `**` 负指数或溢出返回 float，非法结果为 runtime 错误。

## 4. 求值

### 4.1 节点

- 节点头按顺序解析为特殊形式 → 用户绑定 → 内置函数 → `unknown-node`；
- 特殊形式先于用户绑定（不能覆盖 `cond` 等）；
- 用户函数与内置函数同名时，用户绑定优先；
- 参数从左到右求值，特殊形式自行决定求值范围。

### 4.2 函数

- `(node f (a b) body…)` 定义闭包；
- 参数个数必须精确匹配，否则 `bad-arg-count`；
- 函数体最后一个表达式为返回值；`hand` 提前返回；
- 调用深度上限 300，超限 `stack-overflow`；
- 闭包捕获定义环境。

### 4.3 特殊形式

| 语义 | 规范拼写 | 别名 |
|---|---|---|
| 定义 | node | ✦ mint ✧ |
| 绑定 | letv | ⊂ engrave |
| 重绑定 | rebind | set! ⊃ |
| 记录 | rec | record map ◫ |
| 条件 | cond | branch ▷ |
| 循环 | spin | iterate ↺ |
| 遍历 | scan | sweep ⟲ |
| 返回 | hand | -> ⊳ |
| 运行时调用 | native | foreign ffi ⚡ |
| 打印 | print | log ◇ |
| 中断 | sever | escape ⏏ |
| 继续 | resume | proceed ⏩ |
| 与 | conjoin | both ⊓ ⋏ |
| 或 | alt | either ⊔ ⋎ |
| 捕获 | try | attempt probe |

`cond` 的 `then`/`lest` 是节点头；`cond` 是表达式，不会提前结束函数；
需要提前返回必须 `(hand …)`。

### 4.4 控制信号

- `hand` → 返回信号，由函数/模块捕获；
- `sever` / `resume` → 由最近循环捕获；无循环时报 runtime 错误；
- `try` 只捕获语言错误（lex/parse/type/name/runtime/host），不捕获上述信号。

### 4.5 模块结果

1. 最后一条顶层 `hand` 的值；否则
2. 最后一条顶层裸表达式的值；否则
3. `◌`。

语句：`node`、`letv`、`rebind`、`print`、`spin`、`scan`、`sever`、`resume`、`hand`。

## 5. 运行时接口

运行时函数通过 `(native 名称 参数…)` 调用；名称可以是标识符或字符串。
C 引擎内置：

| 函数 | 签名 | 说明 |
|---|---|---|
| `store.list` | `(coll) → list` | 集合记录列表 |
| `store.get` | `(coll, id) → rec \| ◌` | 按数字 id |
| `store.put` | `(coll, rec) → rec` | 有 id 且存在则替换，否则分配 max(id)+1 |
| `store.patch` | `(coll, id, changes) → rec \| ◌` | 浅合并 |
| `store.remove` | `(coll, id) → bool` | 删除 |
| `store.count` | `(coll) → int` | 条数 |
| `store.clear` | `(coll) → int` | 清空并返回删除数 |
| `clock.now` | `() → str` | UTC ISO 毫秒 |
| `lib.say` | `(text) → void` | 写日志 |
| `lib.emit` | `(payload) → void` | 事件 |
| `lang.run` | `(file, fn, args) → any` | 新解释器加载文件并调用函数 |
| `lang.eval` | `(source) → any` | 新解释器求值 |
| `lang.names` | `() → list` | 当前全局函数名 |

### 5.1 纯求值模式

`eval --pure` 使用空运行时表：普通表达式、闭包、列表、记录可用；
任何 `native` 调用返回 `host` 错误 `host-disabled: <name>`。
这证明求值器本身不依赖 I/O 或宿主。

### 5.2 运行时表是可选的

C API `interp_new(NULL, out)` 可在没有任何运行时函数的情况下求值纯表达式；
CLI 默认创建带 `store/clock/lang/lib` 的运行时表。

## 6. 错误

统一为 `{kind, message, line}`：

| kind | 说明 |
|---|---|
| lex | 词法错误 |
| parse | 语法错误 |
| type | 类型/参数个数错误 |
| name | 未知名称/节点 |
| runtime | 除零、栈溢出、循环上限、信号越界 |
| host | native 未知/参数错/纯模式禁用 |

CLI 错误输出 `{"error": {…}}`，退出码 1。

## 7. 限制

| 项 | 值 |
|---|---|
| 调用深度 | 300 |
| 单次求值循环 | 5,000,000 |
| 整数安全范围 | ±2^53 |
| 字符串大小写 | ASCII |
| 字符串索引 | Unicode 码点 |
| 记录键 | 非纯数字字符串 |
