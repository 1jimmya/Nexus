## Nexus (`.nx`)

A Nexus program is a *node network*: code and data have the same shape, a prefix node `(head arg …)`. There is no operator precedence at all — nesting is the precedence. Parentheses and angle brackets (`(`/`)` vs `⟨`/`⟩`) are interchangeable and can be mixed inside one expression, and every node head has word and symbol aliases.
