# Nexus 语法手册（1.1.0）

> 本手册覆盖 Nexus 1.1.0 的完整语法、特殊形式、内置函数、错误与运行时边界。
> 形式化规范见 `完整语言规范.md`，全部拼写别名见 `别名总表.md`。

---

## 0. 文件与编码

- 扩展名：`.nx`；
- 编码：UTF-8，**无 BOM**；换行 LF 或 CRLF 均可；
- 一个文件由若干顶层表达式组成，加载时按顺序求值；
- 注释：`;` 到行尾；`⸢ … ⸣` 块注释（可跨行）；
- 没有 `//`、`/* */`、`#` 注释（`#t`/`#f` 是布尔字面量）。

```lisp
; 行注释
⸢ 块注释
   可跨行 ⸣
```

## 1. 词法

### 1.1 空白与分隔

空白：空格、Tab、回车、换页、垂直制表、换行。
分隔符：`(` `)` `[` `]` `,` `;` `"` `'` `⸢` `⸣`；`⟨` `⟩` 等价于 `(` `)`。

### 1.2 数字

```
-?(?:\d+(?:\.\d*)?|\.\d+)(?:[eE][+-]?\d+)?
```

- 无小数点/指数：整数，范围 ±2^53；超出按浮点处理；
- 有小数点或指数：IEEE 双精度；
- `-` 后必须紧跟数字或 `.`，否则按标识符处理。

### 1.3 字符串

单引号或双引号等价。支持的转义：

```
\n  \t  \r  \b  \f  \\  \"  \'
```

其他 `\x` 保留反斜杠后的字符（例如 `\u` 得到 `u`，**不解析 Unicode 转义**）。
字符串不能跨行。

### 1.4 布尔与空值

| 真 | 假 | 空值 |
|---|---|---|
| `#t` `⊤` `◉` | `#f` `⊥` `◯` | `◌` `○` `⌀` |

### 1.5 标识符

除空白、括号、列表括号、逗号、引号、分号、块注释符号外的连续字符。
因此 `+`、`->`、`store.list`、`水温` 都是合法标识符/函数头。

### 1.6 数字与字符串的 JSON 表示

`text`/`json` 使用紧凑 JSON：

- `text 3` → `"3"`，`text 3.5` → `"3.5"`；
- 记录/列表 → `{"k":1,"a":[1,2]}`；
- 字符串按 JSON 规则转义，非 ASCII 原样输出。

## 2. 语法

### 2.1 EBNF

```ebnf
program  := expr*
expr     := node | seq | atom
node     := '(' word expr* ')' | '⟨' word expr* '⟩'
seq      := '[' expr* ']'
atom     := number | string | bool | nil | word
```

- 逗号 `,` 在节点/序列中可作可选分隔，会被忽略；
- 空节点 `()` 可以解析，但**求值时报 `empty-node`**；
- 节点头必须是词；`(1 2)` 这类会报 `bad-head`；
- 没有运算符优先级，嵌套就是优先级。

### 2.2 求值顺序

节点参数从左到右求值；特殊形式自行决定求值哪些参数（例如 `cond` 只求值命中分支）。

## 3. 值模型

### 3.1 类型

| 类型 | 说明 |
|---|---|
| void | `◌`，空值 |
| bool | `#t` / `#f` |
| int | ±2^53 安全整数 |
| float | 双精度；整数值浮点在 `norm`/算术中会转 int |
| string | UTF-8 字符串，长度/索引/切片按 Unicode 码点 |
| list | 有序列表 |
| record | 保序键值记录；键必须是非纯数字字符串 |
| function | 用户函数（闭包）或内置函数 |

### 3.2 真值

只有 `#f` 和 `◌` 为假；`0`、`""`、`[]`、`(rec)` 都为真。

### 3.3 相等

- 数字按数值比较（`1 == 1.0` 为真）；
- 字符串按内容；
- 列表逐元素、记录按键值深度比较；
- 布尔、void、函数按类型/标识比较。

### 3.4 数字边界

- 整数字面量超过 ±2^53 转浮点；
- 算术结果超出安全整数范围转浮点；
- `/` 能整除得 int，否则 float；除零报 `divide-by-zero`；
- `%` 向零截断：`(% -7 3) ⇒ -1`。

## 4. 绑定与函数

| 语义 | 写法（全部等价） |
|---|---|
| 定义变量 | `(letv x 1)`、`(⊂ x 1)`、`(engrave x 1)` |
| 修改已有变量 | `(rebind x 2)`、`(set! x 2)`、`(⊃ x 2)` |
| 定义函数 | `(node f (x) body…)`、`(✦ f (x) body…)`、`(mint …)`、`(✧ …)` |

- 函数参数表：`(x)`、`(a b)`、`()`；
- 函数体是后面所有表达式，返回最后一个值；
- 函数是闭包，捕获定义时的环境；
- `rebind` 找不到变量报 `unknown-name`；
- 函数参数个数必须精确匹配，否则 `bad-arg-count`；
- 调用深度上限 300。

```lisp
(node make-adder (n)
  (node adder (x) (+ x n))
  adder)
(letv add5 (make-adder 5))
(add5 10)        ; 15
```

## 5. 特殊形式

| 语义 | 拼写 |
|---|---|
| 函数/值定义 | `node` `✦` `mint` `✧` |
| 绑定 | `letv` `⊂` `engrave` |
| 重绑定 | `rebind` `set!` `⊃` |
| 记录构造 | `rec` `record` `map` `◫` |
| 条件 | `cond` `branch` `▷` |
| 循环 | `spin` `iterate` `↺` |
| 遍历 | `scan` `sweep` `⟲` |
| 返回 | `hand` `->` `⊳` |
| 运行时调用 | `native` `foreign` `ffi` `⚡` |
| 打印 | `print` `log` `◇` |
| 中断循环 | `sever` `escape` `⏏` |
| 继续循环 | `resume` `proceed` `⏩` |
| 逻辑与 | `conjoin` `both` `⊓` `⋏` |
| 逻辑或 | `alt` `either` `⊔` `⋎` |
| 捕获错误 | `try` `attempt` `probe` |

### 5.1 `cond`

```lisp
(cond 条件
      (then 表达式…)
      (lest 表达式…))
```

- `then`/`lest` 是节点头，体可以多条；
- 不写 `lest` 且条件不成立 → `◌`；
- `(cond 条件 A B)`（无 then/lest）→ A 为真分支、B 为假分支；
- 多个并列 `cond` **不会提前结束函数**；要提前返回必须在 `then` 里 `(hand …)`。

### 5.2 `spin`

```lisp
(spin 条件 体…)
```

每轮先求条件，为真执行体；循环次数计入全局 5,000,000 上限。

### 5.3 `scan`

```lisp
(scan x 列表 体…)
(scan c "文本" 体…)
(scan k 记录 体…)
```

- 列表：绑定元素；
- 字符串：绑定单码点字符串；
- 记录：绑定键字符串；
- 体执行结果被丢弃；循环结束返回 `◌`。

### 5.4 `hand` / `sever` / `resume`

- `(hand 值)`：从当前函数立即返回；顶层作为模块结果；
- `(hand)`：返回 `◌`；
- `(hand a b)`：返回 `[a b]`；
- `(sever)`：跳出最近循环；
- `(resume)`：继续最近循环的下一轮。

### 5.5 `try`

```lisp
(try 表达式…)
```

成功：`{ok:#t, value:值}`；
失败：`{ok:#f, value:◌, kind:错误类型, message:消息, line:行号}`。
只捕获语言错误，不捕获 `hand`/`sever`/`resume` 信号。

### 5.6 `native`

```lisp
(native 名称 参数…)
```

名称可以是标识符或字符串；由运行时函数表解析（见第 8 节）。

## 6. 内置函数

### 6.1 算术与比较

| 函数 | 说明 |
|---|---|
| `(+ a b …)` | 数字相加；字符串/列表拼接；无参 0 |
| `(- a b …)` | 相减；单参取负 |
| `(* a b …)` | 相乘；无参 1 |
| `(/ a b …)` | 相除；整数整除得 int |
| `(% a b)` | 取余（向零截断） |
| `(** a b)` | 幂；负指数得 float |
| `< <= > >=` | 数字或字符串比较 |
| `== !=` | 深度相等/不等 |
| `not` | 逻辑非（单参） |

### 6.2 集合与字符串

| 函数 | 说明 |
|---|---|
| `len` | 字符串码点数 / 列表长度 / 记录键数 |
| `text` | 转文本 |
| `num` | 严格转数字，失败 `type` 错误 |
| `norm` | 整数浮点→int；数字字符串→数字；其他原样 |
| `lower` `upper` | 大小写（仅 ASCII） |
| `split s sep` | 分隔；`sep=""` 按码点 |
| `join list sep` | 拼接 |
| `contains coll x` | 子串 / 列表成员 / 记录键 |
| `keys` `values` | 记录键/值列表 |
| `append list x` | 返回新列表 |
| `slice x start end` | 支持负索引；end 为 `◌` 表示到末尾 |
| `sort list` | 数字或字符串列表 |
| `sum list` | 求和 |
| `json x` | 紧凑 JSON 字符串 |
| `kind x` | 类型名 |
| `trim s` | 去首尾空白 |
| `get coll key` | 列表/字符串索引、记录键；越界/缺失→`◌` |
| `assoc rec key value` | 返回新记录 |

完整别名（如 `len`/`length`/`count`/`size`、`get`/`at`/`index`/`lookup`）见 `别名总表.md`。

## 7. 模块结果

一个 `.nx` 文件的结果：

1. 最后一条顶层 `hand` 的值；否则
2. 最后一条顶层“裸表达式”的值；否则
3. `◌`。

语句（不计入裸表达式）：`node`、`letv`、`rebind`、`print`、`spin`、`scan`、`sever`、`resume`、`hand`。

## 8. 运行时接口与“无宿主”

**“无宿主”指不依赖 Python / JavaScript / 虚拟机或外部宿主进程。**
词法、语法、求值、值模型、JSON、存储、时钟、程序加载全部在 `nexus.c` 里实现，
编译成一个 `nexus.exe` 即可运行，不需要安装任何语言运行时。

但任何程序都要和操作系统打交道，I/O 仍然存在，只是由 **C 引擎自身**完成：

| 能力 | 实现方式 |
|---|---|
| `print` / `lib.say` | 标准输出（C stdio） |
| `store.*` | 本地 JSON 文件（C stdio） |
| `clock.now` | 操作系统时间（C 标准库） |
| `lang.run` / `lang.eval` | C 引擎内部再次词法/语法/求值 |
| `native …` | C 引擎内置运行时函数表 |

所以：

- **不是**“没有 I/O”；
- **不是**“需要另装宿主语言”；
- 是“I/O 与运行时函数也由 C 实现，没有外部宿主进程”。

### 纯求值模式

如果只需要验证语言本身、不触碰任何 I/O，可以用 `--pure`：

```powershell
.\可执行程序\nexus.exe eval --pure "(+ 1 2)"
# 3

.\可执行程序\nexus.exe eval --pure "(native clock.now)"
# {"error": {"kind": "host", "message": "host-disabled: clock.now", ...}}
```

`--pure` 下运行时函数表被禁用，`native` 调用会得到 `host-disabled`；
普通表达式、闭包、列表、记录等完全可用。这证明求值器本身不依赖宿主。

## 9. 错误

| kind | 触发示例 |
|---|---|
| `lex` | 未闭合字符串/注释、坏数字 |
| `parse` | 缺右括号、空节点、坏节点头 |
| `type` | 参数类型错、参数个数错、除零以外的类型问题 |
| `name` | 未知变量/函数/节点 |
| `runtime` | 除零、栈溢出、循环上限、`hand`/`continue` 越界 |
| `host` | `native` 未知函数、`--pure` 下调用 native、运行时参数错 |

CLI 错误输出：`{"error":{"kind":…,"message":…,"line":…}}`，退出码 1。

| 项 | 值 |
|---|---|
| 调用深度 | 300 |

| 整数安全范围 | ±2^53 |
| 字符串大小写 | ASCII |
| 字符串索引/长度 | Unicode 码点 |
| 记录键 | 非纯数字字符串 |

## 11. 完整示例

```lisp
; 统计 1..n 的平方和
(node sum-squares (n)
  (letv i 1)
  (letv total 0)
  (spin (<= i n)
    (rebind total (+ total (* i i)))
    (rebind i (+ i 1)))
  (rec "n" n "total" total))

(sum-squares 10)
; {"n":10,"total":385}
```
