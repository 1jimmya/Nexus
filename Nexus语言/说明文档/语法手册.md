# Nexus 语法手册（1.1.0）

> 本手册描述 Nexus 1.1.0 的语法与边界，对应本仓库的 C 引擎实现。
> 写任何 `.nx` 之前先读一遍，写完用 `python nexus.py run <file.nx>` 真跑一次。

## 0. 文件与加载

* 扩展名 `.nx`，UTF-8 **无 BOM**，换行 LF。
* `.nx` 为 UTF-8（无 BOM）；`run` 只负责求值，不强制模块结构。
* 宿主可用 `lang.run` 加载其他 `.nx` 并调用其中一个函数。
* 每次 `lang.run` 都会新建解释器，模块级可变状态不跨调用保留；需要持久化请用宿主 store。
* 注释：`;` 到行尾。`(`/`)` 与 `⟨`/`⟩` 完全等价。

## 1. 值与字面量

| 写法 | 含义 |
|---|---|
| `42` `-7` `3.5` | 整数 / 浮点 |
| `"文本"` `'文本'` | 字符串，支持 `\n \t \r \" \\` 等转义 |
| `#t` `#f` | 布尔真 / 假 |
| `◌` `○` `⌀` | 空值 void |
| `[1 2 3]` | 列表字面量（空格或逗号分隔，可换行） |
| `(rec "k" v "k2" v2)` | 记录（键必须是**非纯数字**字符串） |

* 记录保持插入顺序；`keys`/`values` 按该顺序返回。
* 数字归一化：整数值的浮点会自动变 int（`3.0` ⇒ `3`）。

## 2. 特殊形式（全部拼写都可用，用最左边那个即可）

| 语义 | 写法 |
|---|---|
| 定义函数/值 | `(node 名 (参数…) 体…)` / `(node 名 表达式)` |
| 局部绑定 | `(letv x 值)` |
| 修改已有绑定（可改外层闭包变量） | `(rebind x 值)` |
| 记录 | `(rec "k" v …)` |
| 条件 | `(cond 条件 (then 体…) (lest 体…))` |
| while | `(spin 条件 体…)` |
| foreach | `(scan x 集合 体…)` |
| 提前返回 | `(hand 值)` |
| 宿主调用 | `(native store.list "yonghu")` |
| 逻辑 | `(conjoin a b …)` / `(alt a b …)` / `(not a)` |
| 返回成功/失败的探测 | `(try 体…)` ⇒ `{ok, value, kind, message, line}` |
| 中断/继续 | `(sever)` / `(resume)` |
| 打印（会写宿主日志） | `(print 值…)` |

`cond` 的坑：
* `then`/`lest` 是**节点头**，体可以有多条：`(then (letv x 1) (rebind out x))`。
* 不写 `lest` 时条件不成立返回 `◌`。
* **`cond` 只是表达式，不会结束函数**：函数体会继续往下执行！想要「命中即返回」，
  必须在 `then` 体里写 `(hand 值)`，例如：
  `(cond (== s "zhiban") (then (hand "值班员")))`。
  多个并列 `cond` 各自独立求值，最后一个表达式才是函数返回值。
* 没有 `else if` 语法，多分支就写多个 `cond` + `hand`，或嵌套 `(cond c1 (then …) (lest (cond c2 …)))`。
* 判断「有/无」用 `(== x ◌)`，不要用 `(== x ◌)` 也行，但 `◌` 更稳。

自定义函数返回**函数体最后一个表达式的值**；需要提前返回用 `(hand 值)`。

## 3. 内置函数（只有这些）

| 语义 | 可用写法 | 说明 |
|---|---|---|
| 算术 | `+ - * / % **` | 都是节点：`(+ a b)` |
| 比较 | `< <= > >= == !=` | 字符串也能比大小 |
| 取字段/下标 | `(get rec "k")` `(get lst 0)` | 缺失记录键、越界下标 ⇒ `◌` |
| 更新记录 | `(assoc rec "k" v)` | 返回新记录，不改原值 |
| 长度 | `(len x)` | 字符串/列表/记录 |
| 转文本 | `(text x)` | 数字→十进制；记录/列表→紧凑 JSON |
| 转数字 | `(num "12")` | 失败抛 `type` 错误 |
| 数字归一 | `(norm x)` | 整数值浮点→int；**不是**去空白 |
| 大小写 | `(lower s)` `(upper s)` | 只接受字符串 |
| 拆分/拼接 | `(split s sep)` `(join lst sep)` | `(split s "")` ⇒ 单字符列表 |
| 包含 | `(contains 集合 x)` | 字符串子串 / 列表深比较 / 记录键 |
| 键/值 | `(keys rec)` `(values rec)` | |
| 追加 | `(append lst v)` | 返回新列表 |
| 截取 | `(slice s 起 止)` | 止不含；支持负数下标 |
| 排序 | `(sort lst)` | **只接受全数字或全字符串**，记录列表要自己排 |
| 求和 | `(sum lst)` | |
| JSON | `(json x)` | 序列化成字符串 |
| 类型名 | `(kind x)` | `int float string list record bool void function` |
| 去首尾空白 | `(trim s)` | 只接受字符串 |

**没有**：`replace`、`index-of`、`abs`、`min`、`max`、`floor`、`ceil`、`char-code`、
`map/filter/reduce`、`printf`。这些都要自己用循环写（本项目里已经写好了一批，见 `haifeng_gongju.nx`）。

## 4. 数值细节

* `/` 能整除返回 int（`6/2 ⇒ 3`），否则 float（`7/2 ⇒ 3.5`）；除零抛 `runtime divide-by-zero`。
* % 采用向零截断语义：(% -7 3) ⇒ -1。取下标/分页时注意负数。
* 想取整除法：`(- (/ a b) (% a b))` 不对；写 `(zhengchu a b)` 这种辅助：`(norm (- (/ a b) 0.5))` 不可靠，用循环或 `(if (== (% a b) 0) (/ a b) (norm (- (/ a b) 0.5)))`，更稳的是自己写 `(intdiv a b)`：反复减太慢，直接用 `(+ (- a (% a b)) )` 再除以 b。
* 整数安全范围 ±2^53；`**` 结果可能是 int。
* 浮点显示：`(text 3.5)` ⇒ `"3.5"`；`(text 3)` ⇒ `"3"`。

## 5. 循环与递归

* `scan` 遍历列表元素 / 字符串字符 / 记录键。
* 循环预算每次 eval 5,000,000 次迭代（`spin`/`scan` 每轮计 1），正常够用。
* 递归深度上限 300 层。**不要写深层递归解析器**，改用显式下标 + 循环：
  * 例如 SQL 词法/语法用「下标游标 + `spin`」，每层只调浅函数。
* 典型模式：

```nexus
(node zhaochu (lst mubiao)
  (letv i 0)
  (letv out -1)
  (spin (< i (len lst))
    (cond (== (get lst i) mubiao)
        (then (rebind out i) (sever)))
    (rebind i (+ i 1)))
  out)
```

闭包写状态机（已验证可用）：

```nexus
(node jishuqi ()
  (letv n 0)
  (node jia () (rebind n (+ n 1)))
  (jia) (jia)
  n)                      ; ⇒ 2
```

## 6. 宿主函数

Nexus 不绑定 I/O；宿主通过 `native` 注入函数：

```lisp
(native store.put "users" (rec "name" "Ada"))
(native clock.now)
(native lib.say "hello")
```

CLI 宿主提供的函数：

| 名字 | 说明 |
|---|---|
| `store.list/get/put/patch/remove/count/clear` | JSON 集合存储 |
| `clock.now` | UTC ISO 毫秒时间 |
| `lib.say` / `lib.emit` | 输出 / 事件 |
| `lang.run(file, fn, args)` | 新解释器加载文件并调用函数 |
| `lang.eval(source)` | 求值字符串 |
| `lang.names` | 当前全局函数名 |

嵌入时可以实现同名函数，接口见 `USAGE.md`。

## 7. 错误处理

```lisp
(try (/ 1 0))     ; {ok:#f, kind:"runtime", line:…}
(try (+ 1 2))     ; {ok:#t, value:3}
```

错误类型：`lex`、`parse`、`type`、`name`、`runtime`、`host`。
`try` 只捕获错误，不捕获 `hand` / `sever` / `resume` 信号。

## 8. 快速示例

```lisp
(node square (x) (* x x))
(letv n 9)
(square n)                    ; 81

(letv xs [3 1 2])
(rec "sorted" (sort xs) "sum" (sum xs))

(node fact (n)
  (cond (== n 0) (then (hand 1)))
  (hand (* n (fact (- n 1)))))
(fact 6)                      ; 720
```

更多示例见仓库 `示例/`。

## 9. 运行与检查

```powershell
.\bin\nexus.exe run examples\hello.nx
.\bin\nexus.exe test
python nexus.py test
```

如果表达式有语法问题，`run` 会输出 `{"error": {...}}` 并以非零码退出；
在 REPL 里输入 `:help` 可查看交互命令。
