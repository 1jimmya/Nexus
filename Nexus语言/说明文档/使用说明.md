# Nexus 使用说明

本说明对应本目录的 **C 引擎版**（`解释器源代码\nexus.c` / `可执行程序\nexus.exe`）。
语法细节见 [`语法手册.md`](语法手册.md)。

---

## 1. 运行环境

- Windows 10/11（本发行包提供 `nexus.exe`）；
- 无需安装 Python、Node.js 或其他运行时；
- 如需重新编译：MSVC / gcc / clang 任一即可。

---

## 2. 双击运行

双击根目录 **`Nexus解释器.exe`**，或在 PowerShell 中：

```powershell
.\Nexus解释器.exe
.\可执行程序\nexus.exe
```

不带参数时会直接进入交互式解释器。

## 2.1 Nexus 专用浏览器

双击根目录 **启动浏览器.exe**，打开原生 Nexus 浏览器：上方是地址栏和前进/后退/刷新/首页，
页面由 浏览器\页面\*.nx 返回文档树后渲染。默认 
exus://home，可输入 
exus://语法示例
或本地 .nx 文件路径。浏览器源码：浏览器\Nexus浏览器.py。

---

## 3. 交互式 REPL

```
Nexus 1.1.0 交互解释器（C 引擎，无宿主）
输入 :help 查看命令，:quit 退出。
nexus> (+ 1 2)
3
nexus> (node square (x) (* x x))
null
nexus> (square 9)
81
nexus> :help
nexus> :quit
```

命令：

| 命令 | 说明 |
|---|---|
| `:help` | 显示帮助 |
| `:load <文件>` | 在当前解释器载入并求值一个 `.nx` 文件 |
| `:quit` / `:q` | 退出 |
| `Ctrl+C` / `Ctrl+D` | 退出 |

括号未闭合时会自动续行，提示符变为 `...>`。

---

## 4. 命令行

```powershell
.\可执行程序\nexus.exe version
.\可执行程序\nexus.exe run 示例\hello.nx
.\可执行程序\nexus.exe ast 示例\hello.nx
.\可执行程序\nexus.exe tokens 示例\hello.nx
.\可执行程序\nexus.exe test
.\可执行程序\nexus.exe help
```

`run` 输出模块结果的 JSON；`print` / `lib.say` 输出到 stderr。

退出码：0 成功，1 求值/解析错误，2 用法错误，3 致命错误。

---

## 5. 运行模型

一个 `.nx` 文件的模块结果：

1. 最后一条顶层 `hand` 的返回值；否则
2. 最后一条顶层裸表达式的值；否则
3. `◌`。

错误输出：

```json
{"error": {"kind": "runtime", "message": "divide-by-zero", "line": 12}}
```

错误类型：`lex`、`parse`、`type`、`name`、`runtime`、`host`。

限制：

| 项 | 值 |
|---|---|
| 调用深度 | 300 |
| 单次求值循环上限 | 5,000,000 |
| 整数安全范围 | ±2^53 |
| 字符串大小写 | 当前仅 ASCII |

---

## 6. 宿主函数

CLI 自带宿主：

| 函数 | 说明 |
|---|---|
| `store.list/get/put/patch/remove/count/clear` | JSON 集合存储 |
| `clock.now` | UTC ISO 毫秒时间 |
| `lib.say` / `lib.emit` | 输出 / 事件 |
| `lang.run(file, fn, args)` | 新解释器加载文件并调用函数 |
| `lang.eval(source)` | 求值字符串 |
| `lang.names` | 当前全局函数名 |

默认数据文件 `data/nexus.json`（可用环境变量 `NEXUS_DATA` 覆盖）；
`lang.run` 默认从 `programs/` 目录加载。

---

## 7. 编译 C 引擎

右键“使用 PowerShell 运行”`编译脚本\编译C引擎.ps1`，或：

```powershell
.\编译脚本\编译C引擎.ps1
```

脚本会优先查找 MSVC，找不到时回退 `gcc` / `clang`，输出 `可执行程序\nexus.exe`。

手工编译：

```bash
gcc -std=c11 -O2 -o 可执行程序/nexus.exe 解释器源代码/nexus.c
```
